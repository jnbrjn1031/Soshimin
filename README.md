# 소시민

2026년 대한민국에서 평범한 한 사람으로 태어나 한 생을 걸어 보는 인생 시뮬레이션.

## 플레이하기

**▶ https://jnbrjn1031.github.io/Soshimin/**

브라우저에서 바로 열립니다. 설치는 필요 없고, 저장은 그 브라우저 안(localStorage)에 남습니다.

오프라인으로 하려면 `소시민.html`을 내려받아 브라우저로 열면 됩니다.

어떤 삶으로 태어날지 고르고 싶다면 **[운명 번호표](SEEDS.md)**에서 번호를 골라 첫 화면의 「운명 번호로 태어나기」에 넣으세요.

## 배포

`main`에 push하면 `.github/workflows/pages.yml`이 `소시민.html`을 `index.html`로 만들어 GitHub Pages에 올립니다.
처음 한 번만 저장소 **Settings → Pages → Build and deployment → Source**를 **GitHub Actions**로 바꿔 두세요.
